***
2026-09-22 - Initial fork

* Target ESPHome 2026.9+ on ESP32 (Seeed XIAO ESP32-C6 as reference hardware).
  Dropped ESP8266 support from docs and examples.
* Fixed StringToFanLevel: was comparing raw pointers, so Home Assistant custom
  fan modes (Low-Medium, Medium-High) were silently ignored.
* Hardened UART RX buffer: reserved up-front and capped at 128 bytes with
  warn-and-discard on overflow. Fixes std::bad_alloc crash observed on
  ESP32-C6 with a floating RX pin / no UART peer connected.
* Const-correctness and const-ref parameters on hot paths (send_to_uart,
  checksum); moved static handshake tables from the header to the .cpp.
* GCC 14 / ESPHome 2026.9 warning cleanup: dropped meaningless top-level
  const on return-by-value signatures, added explicit int casts for enum
  %d format specifiers, wrapped LogString values with LOG_STR_ARG().
* Example YAMLs enable Home Assistant API encryption and encrypted OTA by
  default; both examples share a common set of secrets.yaml keys.
* Added example_esp32c6_xiao.yaml - full Seeed XIAO ESP32-C6 build.
* No wire-protocol bytes changed.
